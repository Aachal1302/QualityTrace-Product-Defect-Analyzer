
# QualityTrace — Product Defect Analyzer

## Project Overview
QualityTrace is a manufacturing quality analysis project focused on identifying product defects in casting production and monitoring defect rates across machines, production lines, and shifts.

## Tools Used
- PostgreSQL — Data analysis using SQL
- Microsoft Excel — Data validation and inspection
- Power BI — Interactive dashboard and visualization

## Dataset
- 4,800 production records
- 3 production lines and 3 machines
- 2 shifts and 15 operators
- Period: January–June 2024

## Key Analysis
- Machine-wise defect rate
- Shift-wise defect rate
- Production line-wise defect rate
- Defect-type frequency
- Process parameters associated with defects

## Key Findings
- Overall defect rate: 32.23%
- Machine M-03 had the highest defect rate at 38.95%.
- Night shift defect rate was 34.86%.
- Misrun was the most frequent defect type.

## Project Outcome
Developed an interactive Power BI dashboard to monitor manufacturing quality, compare defect rates, and identify areas requiring improvement.

## Recommendations
- Investigate Machine M-03 to identify the root causes of its high defect rate.
- Review night-shift production processes and operator practices to reduce defects.
- Analyze the most frequent defect, Misrun, and review relevant casting process parameters.
- Monitor mold temperature, core temperature, moisture, and sand ratio to identify potential quality issues.
- Track defect rates regularly using the Power BI dashboard and compare performance against the 25% target.
- Implement corrective actions and monitor their effectiveness to improve production quality.
